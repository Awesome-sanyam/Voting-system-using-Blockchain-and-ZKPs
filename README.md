# BlockVote-India

A Decentralized E-Voting Ecosystem Using Secured Blockchain and Zero-Knowledge Cryptography.

## Architecture

* **Frontend**: Flutter (Web/Mobile), Dart
* **Backend**: Python (Django, Django Channels/WebSockets, Django REST Framework), Web3.py, Redis, PostgreSQL
* **Blockchain**: Polygon Network, zk-SNARKs, Gasless Meta-Transactions
* **AI/Security**: Isolation Forest (Scikit-Learn) for DDoS/botnet detection

## Modules
1. **The Voter (Citizen Portal)**: Registration, OTP Authentication, TOTP QR Session Security, zk-SNARK Voting.
2. **The Administrator (Election Commission)**: Configuration, Identity Oversight, Merkle Root Lock, AI Threat Dashboard.
3. **The Auditor (Independent Observer)**: Public Transparency, Live Mempool Tracking, Mathematical Verification.
